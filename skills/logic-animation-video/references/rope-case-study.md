## 真正的非匀速模型

为每根绳子定义累计单头燃烧时间 `T(x)`，其中 `x ∈ [0,1]` 是归一化长度。它单调递增，但不是直线。

```python
models = [
    ([0, .25, .5, .75, 1], [0, 6, 15, 45, 60]),
    ([0, .2, .4, .65, .85, 1], [0, 18, 22, 50, 54, 60]),
]
```

`x = inverse_T(minutes)` 通过单调插值计算。第一根双头烧 30 分钟时在 `x=0.625` 相遇，不是长度中点。

设左火头已消耗的单头时间量为 `L`，右火头为 `R`：

```text
left_position  = inverse_T(L)
right_position = inverse_T(60 - R)
绳子烧尽 ⇔ L + R = 60
```

### 第一阶段，共同经过 t ∈ [0,30]

```text
第一根：L=t, R=t  →  t=30 时烧尽
第二根：L=t, R=0  →  t=30 时剩余单头时间 30
```

### 第二阶段，再经过 δ ∈ [0,15]

```text
第二根：L=30+δ, R=δ
L+R=30+2δ=60 → δ=15
总经过时间 = 30+15 = 45
```

此时第二根左右火头在 `T(x)=45` 对应的位置相遇，约 `x=0.60536`。

## 注意不同时间量

- “已用时间”：观众看到的共同时间 t。
- “剩余单头时间”：整段剩余物质用一个火头烧需要的时间。
- “接下来实际等待时间”：双头情况下为剩余单头时间的一半。

不能把第二阶段剩余单头时间 30 分钟写成还要再等 30 分钟。
