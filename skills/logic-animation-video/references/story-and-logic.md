# 选题、脚本与逻辑校验

## 好题的筛选条件

1. 规则能在 15–25 秒内说明。
2. 核心状态可用道具位置、数量、形状、点火或时间推进表现。
3. 有一个合理但错误的直觉，可以直接演示为何失败。
4. 解答不依赖没告诉观众的隐藏规则。
5. 结尾可以在 10–20 秒内重新演一遍。

推荐题型：燃绳计时、天平找异常球、桥梁过河、真假话约束、有限步搬运、棋盘不变量、帽子推理。选择前检查：人数与时间限制是否足以讲清，能否避免大量静态公式。

## 两分钟结构（可变）

| 环节 | 参考长度 | 动画任务 |
|---|---:|---|
| 钩子与目标 | 0–15 秒 | 道具入场，目标数字出现 |
| 关键限制 | 15–30 秒 | 相同条件下对比不同结果 |
| 直觉错误 | 30–43 秒 | 真正尝试并失败，不只打叉 |
| 可用操作 | 43–59 秒 | 示范允许的操作，留 2–3 秒思考 |
| 核心观察 | 59–72 秒 | 展示因果变化或不变量 |
| 解答第一阶段 | 72–87 秒 | 同步推进多个对象 |
| 解答第二阶段 | 87–104 秒 | 触发事件、改变状态、得到答案 |
| 快速复盘 | 104–122 秒 | 重演全过程，收束问题 |

不是所有题都照搬燃绳的八段结构。保持“讲一句，发生一件相关的事”。

## 独立校验

- 定义状态，例如 `left_burn_minutes`、`right_burn_minutes`、`elapsed_minutes`。
- 明确不变量和终止条件。
- 至少验证起点、转折点和终点；有分支就覆盖所有分支。
- 数学求得的状态驱动动画，避免凭视觉猜路径。
- 如果用示意量代替实际量，直接标注“时间示意”“局部示例”等。

## 燃绳题的完整假设

- 两根绳子各自从任一端点燃，单头完整燃烧为 60 分钟。
- 局部速度不均匀，但确定、稳定，两个方向烧到同一处时所需局部时间相同。
- 两火头互不改变对方尚未燃烧部分的速度，仅在相遇时消耗完毕。
- 可同时点燃多个端点，瞬间转移点火，能观察到烧尽事件。
- 不借助钟表、数秒或其他计时器具。

这是一种理想化模型，真实材料不一定满足。视频中钟面是给观众看的解释工具，不是角色被允许使用的道具。

## 脚本约束

- 自然口语优先，避免一口气念很长的定语。
- 明确区分“长度”“单头剩余燃烧时间”“实际还要等待多久”。
- 不把“剩余绳子不是一半长度”说成普遍必然；准确说法是“不一定是一半长度”。
- 题目来自经典逻辑题时，不声称其题干为独创。
- 医药题附逻辑模型条件，不能变成真实拆药指导；火焰题不加入可模仿的危险实操教学。
