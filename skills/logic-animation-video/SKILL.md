# 中文逻辑谜题动画制作

把逻辑谜题做成**真正可播放的成品 MP4**，不是只交策划、HTML、静态幻灯片或代码。未被用户改写时，采用下列已经确认的系列偏好。

## 1. 默认交付约束

| 项目 | 规范 |
|---|---|
| 格式 | MP4 / H.264 / yuv420p / AAC / faststart |
| 画幅 | **16:9 横屏，1920×1080，30 fps** |
| 时长 | 约两分钟，目标 115–130 秒；示例约 122 秒 |
| 画风 | 中灰纯底、黑白二维手绘人物、细黑轮廓、黄色核心道具 |
| 动画 | 密度至少接近参考；对象动作、过程模拟、推理结果必须可见 |
| 配音 | 中文 TTS，一位稳定的讲述者，清楚、有悬念但不夸张 |
| 字幕 | 简体中文，底部居中、白字深色描边，避免遮挡核心信息 |
| 题材 | 不限选择题；计时、排列、真假、称重、图形、约束推理等均可 |
| 附件 | 封面 JPG、SRT、可复现脚本；优先打开 MP4 |

**不再默认使用上一版竖屏、深蓝背景、3D 木箱、卡片式选择题风格。** 这是用户已经要求纠正的方向。详细依据见 `references/user-preferences.md`。

## 2. 先识别任务，不无谓追问

- 用户已说“自己选题”：自行选择能视觉化、规则完整、答案确定的谜题。
- 已给出原视频：先读取真实画面、时长、画幅；不能只根据标题猜测其内容。
- 页面能打开不等于视频已下载；用实际文件和解码结果区分。
- 参考视频不可获取时，说明限制并请求上传，不声称已经观看。
- 不保证“99%相似”或“必爆”。可描述实际复用的视觉与节奏特点。
- 如果只缺发布仓库地址，先完成本地包，再确认仓库，不拿凭据推测目的地。

## 4. 实际制作流程

### A. 校验谜题

先明确所有规则和理想化假设；独立验证答案。为动画建立状态模型，不能让动画和推理互相矛盾。遇到现实药品、电路、点火等题目，要将逻辑演示与现实操作区分。

### B. 编写约两分钟脚本

通常分 7–9 个配音段落，形成：钩子 → 约束 → 常见错误 → 关键观察 → 留白 → 解答 → 动态复盘。先写能念出来的自然中文，再分镜。不要用虚构“99%的人答错”吸引注意。

### C. 生成可动画化美术资产

生成白底单人物、姿态或单道具，抠出透明前景。文字、数字、绳子火线、时间轴等精确信息在代码中绘制。生图负责美术，代码负责逻辑状态和确定性动作。

### D. 注册或复用 TTS 声音

- 只有当前会话已选定且有效的 voice_id 才能复用。
- 否则先调用可用的声音试听工具，由用户选声；不得把示例会话 ID 当全局音色。
- 独立音频段可并行生成，严格遵守工具字数和调用数限制。
- 生图等不依赖声音选择的工作可以并行。

### E. 测量音频，再确定时间线

以实际 WAV 时长计算分镜。轻度调整语速，并留出 2–3 秒思考区间、片尾尾音。示例用 `atempo=1.18`，它是案例参数，不是永久固定值。

### F. 编排高密度动画

按旁白中的每个因果关系安排对象动作。让点火、分割、移动、排除、相遇、完成等状态真正发生。人物轻微呼吸不是主要动画，不能靠持续缩放或时钟转动冒充高动画密度。

### G. 先看分镜，再渲染

抽取每场景多个关键时刻，检查文字、道具位置和逻辑。复杂项目先渲染低分辨率草稿，再出 1080p。示例入口：

```bash
python scripts/render_rope_demo.py --check
python scripts/render_rope_demo.py --draft
python scripts/render_rope_demo.py
```

### H. 验证并打开成片

```bash
python scripts/validate_video.py deliverables/rope-45-1080p.mp4 --expected-seconds 122 --full-hd
python scripts/check_rope_logic.py
```

检查全片音视频可解码、关键帧无重叠、答案成立、音画顺序一致。环境有 `present_file` 时，**必须打开主 MP4**。最终答复简短说明片名、时长、画幅和可选附件，不让用户自己执行脚本才能看到成片。

## 5. 仓库内的可复现示例

- `scripts/render_rope_demo.py`：1080p 矢量绘制 + AI 生成人物图层 + 真正非匀速燃烧模型 + TTS 合成。
- `examples/rope-45/`：两个人物 PNG、8 段已合成示例 WAV，可离线复现，无需 TTS 密钥。
- `examples/rope-45/narration.json`：配音原稿及序号。
- `scripts/check_rope_logic.py`：验证火线相遇和 45 分钟结论。
- `scripts/validate_video.py`：检查格式、时长、音频流与全片解码。

示例配音仅用于复现，不代表用户已为未来会话永久选定某个工具 voice_id。
