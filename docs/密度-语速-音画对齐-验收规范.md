# 图片密度、语速、TTS发音、音画对齐与成片验收规范

适用：中文机制科普插画短片。下列是本Skill的默认制作/验收目标，不是假定已经通过的结果。每个项目写一份实际检查报告，记录PASS、WARN、FAIL、NOT_RUN和证据；不允许用规则文档代替执行记录。

## 1. 图片密度：同时统计三种数量

- `unique_art_count`：不同内容的独立插画数；同图裁切、推近、调色不算新增。
- `shot_count`：实际镜头段数；连续同图且构图相近的段合并统计有效换图次数。
- `unique_art_per_minute`：独立图数/成片分钟数。
- 默认目标8–12张独立图/分钟；最低6张/分钟是工作版下限，不是优秀成片标准。以机制复杂度优先，不能为了凑数乱配图。
- 镜头中位时长5–9秒，P90尽量≤12秒；单镜通常2.5–12秒，超过15秒须说明原因并增加机制状态变化。
- 同一图原则上≤2次，首尾呼应可例外；例外逐项记入报告。重复出现必须承担相同的概念，不用“万能图”覆盖不同机制。
- 第一次出现新机制、新角色或新层级，优先换对应图。机制图至少明确主体、作用方向和结果。
- 用户要求两轮各10图时，明确本轮10、下轮10，失败请求不计入数量，也不声称跨轮自动执行。
- 本项目目标48张，1.25倍语速后约5分钟，约9.5张/分钟。本轮38张仅作为工作版。

## 2. 语速标准

- 用户设定优先。当前项目语速1.25倍，用atempo保音高，保留原速分段。
- 记录原速字数/分钟、变速后字数/分钟和静音比例；倍率不是同一个声音之间可直接比较的绝对语速。
- 普通知识旁白可先以有效发声时约240–330中文字/分钟作为试听起点；高术语密度内容应更慢。不是硬性平台标准。
- 用户要求1.25倍但术语听不清时：保留全局设置，报告风险，让用户决定局部放慢/停顿，不擅自重写正文或整体改倍率。
- 每个原速TTS段尽量10–35秒；超过35秒标WARN，重点检查后半段与最后一句的声调和漏字。
- 停顿是否加速必须记录。本项目片头1.6秒、每段后0.34秒、片尾2.2秒保持不变。
- 变速后实测每段音频，再重建镜头、字幕、关键词事件。不得只把最终播放器设为1.25倍就宣布交付文件已变速。

## 3. TTS发音自检：机器辅助与人耳验收分开

### 可自动检查
1. 音频能全长解码，声道、采样率、时长合理，非零音频，无意外截断。
2. 对每段执行独立ASR，和原稿规范化后比较：统一标点、空白、大小写，数字/英文缩写差异单独分类，不盲目当错读。
3. 保存原稿、识别稿、差异片段、时间点及词置信度；缺字、重复句、否定词丢失、数字改变、长静音优先列为风险。
4. 低识别置信度不能直接等同错读，高置信度也不能证明声调正确。ASR不是“人耳已确认”，更不是科学事实审核。
5. 术语清单单独检查：线粒体、DNA、ATP、内共生、细胞凋亡、细胞色素c、线粒体夏娃、古菌；本项目还重点检查十五亿到二十亿、母系、通常、并非、脑子等。
6. 原速与1.25倍分别保留，疑点可导出前后各1–2秒的试听片段。

### 必须人工确认的项目
- 多音字、轻声、第三声变调、英文缩写读法是否自然、句尾掉调、情感语气。
- 未获得用户或具备真实听觉的检查者确认时标NOT_RUN/待回听，不编造“逐句试听通过”。
- 修改发音优先重切短句并重配，不擅自改用户要求逐字保留的文本；若改字，先获得允许并记录差异。

## 4. 音频—字幕对齐

- 首先锁定解码后真实音频时间轴。每段起止与实际拼接顺序一致。
- 优先使用语音强制对齐；其次独立ASR词时间戳匹配原文。字数权重只能作为未对齐的兜底，必须标明。
- ASR文本与原文做单调字符匹配，不能直接用错误识别稿替换字幕。匹配不了的局部只在相邻可靠锚点内插值，并记录覆盖率。
- 抽查每段首句、末句、最长句、术语句和所有转场前后。目标：句级起止误差通常≤0.3秒；超过0.5秒列WARN；超过1秒、跨句或累计漂移列FAIL。
- 插值所得的误差不能凭空测量；没有独立人工/强制对齐参考时，不能声称实际误差已低于阈值。
- 字幕单条通常10–24字，超过28字换行或减小字号；显示时间建议≥1秒，避免一两个字闪烁成字幕。
- 逐字动画的时间必须来自当前音频；长句打字速率不能套固定0.6倍时长后宣称逐字同步。

## 5. TTS—图片是否对齐：先语义、再时间

每镜分镜表必须包含：镜号、音频段、原文台词、起止时间、图片文件、机制主张、视觉证据、风险提示。

- 说“氧气接过末端电子”应看到氧气/电子传递，而不是核基因图。
- 说“细胞色素c释放”应看到释放；说“多信号调控”应看到调控网络，不能继续用发电图。
- 说“父母各一半核基因”应看到双方贡献，不能用仅母系树表达。
- 说“基因转移到细胞核”应看到基因转移方向，而不是每次心跳。
- 一个镜头不承载互相矛盾的机制。科普图可示意，但不伪装成精确分子结构/显微实拍。
- 镜头边界尽量在短语或句子边界；概念出现前后约0.3秒内切入最理想。严禁因均分时长把下一个机制提前几秒展示。
- 图片中的箭头、亲缘树、母系线、核与细胞器位置要检查；生成成功不代表科学关系正确。
- 自动文件映射只能验证文件存在。语义对应需要逐镜复核，不能把正则关键词命中称为“理解全部画面”。

## 6. MP4成片自检与报告

### 文件与时间硬检查
- 全长解码无错误；H.264/AAC、yuv420p、1920×1080、25fps（用户另有要求除外）。
- 帧数与规划时间误差≤1帧；音视频尾部差异通常≤0.1秒。MP3/AAC填充需实测，不凭文件容器时长估算。
- 音轨存在，结尾没有截断。分片恢复核对实际帧数/时长，不只看文件大小；改音频或字幕后不能沿用旧分片。
- 不同渲染配置、素材哈希或时长变动时，使用新分片目录或使缓存失效。

### 声音
- 当前推荐立体/单声道按实际内容，旁白响度目标约-20 LUFS，真峰值≤-3dBTP；项目有其他平台规范时以其为准。
- 测 integrated loudness、true peak、意外长静音。旧文档的均值dB不能直接与LUFS等同。
- 不硬凑音量数值：实际报告测量方法、测量值、是否做过处理。

### 画面与字幕
- 检查片头片尾、每个镜头中点、全部接缝±0.2秒及随机运动片段。
- 黑帧/纯色帧检查排除有意片头片尾；静态插画不能只用低帧差判定坏帧。
- 字幕区与图片物理隔离，任何字不得越界；关键词大字不得遮住关键机制，也不得侵入字幕区。
- 安全区至少画幅边缘约5%；缩放要保护主体包围盒。单独查看源图避免把源图本来就截断的内容误判为运镜裁切。
- 转场无闪黑、白闪、重复跳帧；字幕不会因分片重置而提前、重复或倒退。
- 图上所有外加文字可控；无乱码、错误中文字体、意外水印。

### 真实性与版本
- 检查报告至少给出PASS/WARN/FAIL/NOT_RUN列表、软件/模型、检查采样范围、残留问题。
- 图片不足、发音未人工核验、仍有ASR不确定点时标“工作版”，不能宣称终审合格。
- 确認 deliverable 使用的是 selected_voice_id、指定倍率和本轮图片，而不是旧MP4或过期SRT。

## 7. 额外必须注意

- 38–48张高分辨率插画不能全部预载成多层RGBA；采用按镜头读取、有限LRU或分段独立进程，避免内存随素材数增长。
- 渲染结束清理可再生分片前，先验证最终MP4；源码、原图和原速音轨比中间帧更值得保留。
- 备份必须在发布后重新校验最新文件；更改一张图或音轨会使旧SHA清单失效。
- 临时令牌已删除不意味着历史聊天令牌仍有效。后续GitHub写操作实际认证失败时报告阻塞，不把commit称为push。
- 使用外部ASR时说明音频是否离开本机。本项目优先本地CPU推理，模型权重可下载，但音频不上传给ASR服务。
- 不在渲染期间同时克隆大仓库、跑ASR模型或生成大归档。先检查，后渲染，再备份。

- 重复备份生成SHA清单时必须显式排除清单自身，即使它已存在于暂存目录；不能只在复制时忽略它。发现远端校验失败必须修复并重新独立验证。
