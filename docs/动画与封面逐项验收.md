# 动画与封面合规闸门（用户对44图版的纠正）

技术可播放不等于遵循Skill。实际执行的是哪个渲染器，必须核对那个文件，不能拿参考脚本里有某个函数当作已实现。

## 交付前必须有的证据

- 封面：与正片共用米白纸底、限定色板与扁平编辑插画。模型无字背景只作素材；最终交付必须含代码排版的中文标题。
- 零件入场：每镜记录语义零件数、进入顺序、入场0/0.2/0.5/1.2秒序列。只有一个连通域不等于已拆出多个语义零件；禁止机械分成矩形条。
- 多状态：过程镜有状态计划、状态素材与状态切换时间，差异/主体位移/底色一致性校验。尚未制作必须写缺失，不以粒子或整图推拉抵数。
- 运镜：交替推/拉/横移与smoothstep，按完整主体包围盒限制。不同方向的样本需要动态回看。
- 转场：0.42秒溶解及全部接缝前后样本，分段编码不能切坏过渡。
- 字幕：真实音频字锚点不丢失；逐字淡入上浮、关键词强调弹动、荧光笔块、光标都要动态证据。
- 大字：没有固定顶部机制标题。68–124px，7候选留白区、历史惩罚、词频≤2、间隔≥15秒，词的真实发音时刻驱动。回弹、滑入、柔光、扫线、淡出分别核对。
- 留白：在含完整主体的最终画窗上统计，覆盖运镜与所有状态。不能在抠空主体后的背景上检测，否则会把主体位置误当留白。
- 纸带：180px不透明隔离、羽化与纸纹，静态光影预烘焙；所有大字和粒子不进入字幕区。
- 报告：技术、Skill合规、人工观感分三栏。未做的写NOT_RUN，缺失写FAIL，不互相替代。

## 正确工作顺序

先对照实际渲染器列差异 → 修复小样 → 看动态样片 → 补状态素材和语义分层 → 全片渲染 → 技术及合规复检 → 双端备份。

不能只看各镜中点静帧就宣称动画验收。用户未确认的新样片不能称为全片完成。

## 参考代码迁移注意

检查残留标题、文件名、旧关键词；用本项目ASR字时间替换旧均分时间；不要全量预载44张多层图；分片缓存必须绑定代码/素材/字幕/音轨哈希，音轨缺失必须报错。文档和历史脚本的参数不一致时锁定本项目参数并记录，不混用实测数据。
