# 全片动画落地：48图整改的新增约束

## 1. 防止补洞伪影

不要把嵌在一条连续膜里的蛋白质按颜色强行抠走，再用最近邻像素补洞：会把膜上的颜色拉成尖刺/拖影。没有可靠干净底板时，宁可把相连的机制结构作为一个整体入场，使用真实过程状态帧表达内部变化；不能把颜色连通域数冒充人工语义零件数。

本次做法：整块连通主体抠到独立alpha层，纸色统一后使用干净纸底，不在复杂结构内部补洞。连通结构只有1层时如实记录1层。片内过程使用分裂3状态、释放2状态、演化基因转移3状态。

## 2. 生成成功不等于状态可用

本次生成的释放初态，把金色信号点分布在无法确认为膜间隙的位置，故弃用。保留原释放图与后续状态，不为了凑3张把有科学疑点的图放进视频。

- 48张独立基础插画，与额外状态帧分开统计。
- 原计划6张额外状态图，其中1张未入片，因此实际用5张额外状态。
- 共同尺寸比对差异、主体位置和纸底；差异数字不代替语义审核。
- 状态不是现代细胞里实时历史重演。基因转移镜须说明“演化过程示意”。

## 3. 给过程留阅读时间，但不擅自改语速

分裂原镜只有2.44秒，3状态难以读懂。本次在1.2倍音轨90.430–90.948秒的真实静音中，于90.650秒插入1.6秒停顿，分裂镜约4.04秒。保留用户1.2倍语速，所有后续字时间戳和镜头边界统一加1.6秒，字幕正文不变。

不能凭ASR估计就切断发声；先检查真实静音。保存插入点、时长、原音轨和新音轨。不能只修改视频长度，不同步字幕。

## 4. 大字不得从跨镜字幕中捡到上一镜的词

一条字幕可以跨镜，但大字词的实际发音时刻必须属于当前镜。只检查“字幕与镜头有交集”不够：会把已经念过的细菌/线粒体推迟到下一镜。

检查每个词的真实字锚点；如果落在上一镜，跳过该次事件。保留0.5秒开镜缓冲时，也要避免把陈旧词推迟一两秒。复检事件列表、各镜词频与7区域分布。

## 5. 全片性能与缓存

- 限制同时载入的场景数；多状态组也计入内存预算。
- 分段独立子进程渲染，进程结束释放图层/字体/alpha缓存。
- alpha量化缓存需要数量上限和换镜清理，不能在全片积累大图层。
- 分段边界设在转场完成之后；始终使用全局时间计算动画，避免分片重置。
- 缓存签名必须包括封面、字幕、大字布局、音轨、素材、代码和帧区间，不能只看片段文件大小。
- 若经过严格限定的局部修复复用其他片段，必须记录影响范围与验证证据，不盲目提升旧缓存版本。

## 6. 验收状态仍分层

技术解码通过、动画功能实现、人工审美通过、发音终审，是四件不同的事。整片已生成不等于对“脑子”读音已人耳确认；不能自动把NOT_RUN改成PASS。GitHub写入授权缺失时，标未同步，不把MCP成功说成双端成功。
